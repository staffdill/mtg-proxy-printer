# Runbook: Cut only from a saved project

No Python required. Project already contains correctly sized Print Then Cut sheets
(from [03-build-project-and-cut.md](03-build-project-and-cut.md) or a manual equivalent).

## Checklist

1. **My Stuff** → open the project.
2. **Make It** — one mat per sheet (only one sheet fits the PTC area at a time).
3. Prepare screen:
   - **Material Size → Letter (8.5 × 11)** — **every** session; A4 default is wrong.
   - Mirror **off**.
4. Continue → **I’ve Already Printed** (skip printer).
5. Set Base Material (light paper / copy paper starting point).
6. Load LightGrip mat, press **Go**.
7. Peel **mat away from card** (roll mat, don’t yank paper).
8. Sleeve proxy + real card.

## Do not

- Resize layers (they should already be **5.276 in** wide).
- Use glossy laminate.
- Skip Letter material size (registration marks will be wrong).

## If cuts miss

- Re-run Print Then Cut **calibration**.
- Confirm paper is matte and marks are fully on the page.
- Confirm you chose **I’ve Already Printed** on the correct printed sheets.

See [troubleshooting.md](../reference/troubleshooting.md).
